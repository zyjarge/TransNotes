语音合成 (TTS)

MiniMax 语音合成,用于「中文配音」。不配置只影响配音功能,笔记/翻译/导出照常可用。
在 platform.minimaxi.com 控制台获取。仅供本机使用,切勿分发。
新版接口仅用 API Key 认证,旧版账号如有需要可填写。
填写后优先于上方下拉选择;只保存在本机配置中。

文本模型

字幕翻译、AI 概览、自动笔记、助教共用的 OpenAI 兼容服务,默认 DeepSeek。
默认 DeepSeek,可填任意 OpenAI 兼容服务的地址。
适用于 MiniMax M2.5+/M3 等支持 thinking 参数的模型(请求带 thinking: {type:"disabled"}),可显著降低 token 消耗与延迟;老版 MiniMax M2 不支持关闭。其他服务商(如 DeepSeek 非推理模型)不受影响。
开启后,TTS 前的中文字幕会经文本模型润色为自然口语(减少翻译腔/AI 味);英文通道合并进翻译调用,中文直通通道(YouTube 机翻/B 站 ai-zh)单独润色。略微增加耗时与 token 消耗,润色结果与纯翻译分开缓存。

笔记与导出

笔记生成与 Obsidian 导出相关配置。
授权后草稿直接写入该文件夹,截图存 attachments/ 子目录;不设置则导出时下载到「下载目录/video-notes/」。侧边栏导出页可临时切换到其他文件夹。
修改后已生成的概览会在下次生成时按新粒度重建。
长期偏好;侧边栏「笔记」页签里可按视频临时换模板重新生成。
内置模板只读,可「基于此新建」改造成自定义模板;自定义模板可编辑/删除;当前默认模板不可删除,需先把默认切换为其他模板。
系统会自动在提示词后附加硬性规则:时间戳取自字幕行首 [mm:ss]、直接输出 Markdown 不加代码围栏。

TransNotes - 设置

MiniMax TTS(语音合成)

必填。在 platform.minimaxi.com 控制台获取。仅供本机使用,切勿分发。
新版接口仅用 API Key 认证,旧版账号如有需要可填写。

翻译 API(OpenAI 兼容)

默认 DeepSeek,可填任意 OpenAI 兼容服务的地址。AI 概览与翻译共用此配置。
适用于 MiniMax M2.5+/M3 等支持 thinking 参数的模型(请求带 thinking: {type:"disabled"}),可显著降低 token 消耗与延迟;老版 MiniMax M2 不支持关闭。其他服务商(如 DeepSeek 非推理模型)不受影响。

笔记

授权后草稿直接写入该文件夹,截图存 attachments/ 子目录;不设置则导出时下载到「下载目录/video-notes/」。侧边栏导出页可临时切换到其他文件夹。
修改后已生成的概览会在下次生成时按新粒度重建。
长期偏好;侧边栏「笔记」页签里可按视频临时换模板重新生成。

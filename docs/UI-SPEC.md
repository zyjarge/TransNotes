# TransNotes UI 设计规范(提示词版)

> 本文档是 TransNotes 界面的唯一设计标准。新建或修改任何界面时,把本文件作为上下文提供给实现者(人或 AI),所有产出必须与其一致;若需要偏离,先修改本文件再改代码。
> 版本:v1(2026-09-15)| 适用范围:侧边栏、设置页、播放器内浮层(捕捉/截图编辑器/加载浮层/按钮)

---

## 1. 产品气质

TransNotes 是一个"视频辅助学习"工具:配音是耳朵的事,笔记是手的事,助教是嘴的事。
界面气质:**书房案头,不是控制台**——安静、克制、纸张感。所有装饰让位于内容(字幕、笔记、问答)。

五条原则(冲突时按顺序裁决):

1. **内容优先**:任何装饰不得与字幕/笔记/问答争夺注意力
2. **一致性大于局部惊艳**:两个界面做同一件事,必须用同一种做法
3. **时间码是产品语言**:字幕同步、笔记跳转、问答定位都靠时间戳,它是本产品的"一等公民"元素
4. **每个元素只说一件事**:一个控件一个职责;文案写到"用户一看就懂"为止
5. **默认安静**:无装饰性动画、无渐变滥用、无阴影堆砌

## 2. 色彩令牌

唯一的品牌色来自图标(珊瑚红),**克制使用**:只给主行动、选中态、时间码、焦点。其余一律中性灰。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#F7F7F5` | 页面底色(微暖中性灰,不是米色) |
| `--surface` | `#FFFFFF` | 卡片、输入框、浮层 |
| `--panel` | `#F0F0EE` | 次级容器(预览面板、分段控件底) |
| `--line` | `#E9E9E6` | 细分隔线、卡片描边 |
| `--line-strong` | `#D8D8D4` | 输入框描边 |
| `--text` | `#1F2329` | 正文 |
| `--dim` | `#6E7580` | 次要文字、说明 |
| `--faint` | `#9AA1AB` | 占位、极弱提示 |
| `--accent` | `#E6485D` | 品牌珊瑚红:主按钮、选中态、焦点环、时间码 |
| `--accent-soft` | `rgba(230,72,93,.10)` | 时间码/选中态的底色 |
| `--ok` | `#1F9D63` | 成功状态 |
| `--warn` | `#B7791F` | 警告(缓冲等待等) |
| `--err` | `#D9304E` | 错误 |

禁用:任何其他彩色(包括旧版蓝 #3ea6ff/#065fd4)、大面积渐变、彩色描边卡片。
例外:截图编辑器(shotedit)保持深色——图像标注工具的行业惯例,且深色能突出画面内容;
捕捉浮层与草稿提示条为白色主题,与侧边栏一致。

## 3. 字体与排版

不打包字体,全部系统栈(体积与维护成本为零,中文显示依赖系统优化):

- 正文/标题:`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 时间码与数据:`ui-monospace, "SF Mono", Menlo, monospace`

字阶(只允许这五档):

| 角色 | 字号/字重 | 用途 |
|---|---|---|
| 页面标题 | 15px / 600 | 视频标题、设置区标题 |
| 正文 | 13-14px / 400 | 字幕、笔记、问答 |
| 强调 | 同档 / 600 | 卡片标题、章节名 |
| 辅助 | 12px / 400 | meta、hint、说明文字(--dim) |
| 时间码 | 11px / 600(等宽) | 所有时间戳 |

行高:正文 1.6,辅助文字 1.5,标题 1.3。字距:仅时间码 +0.02em。

## 4. 间距 / 圆角 / 阴影

- 间距只允许 4 的倍数:4 / 8 / 12 / 16 / 24
- 圆角:小控件 6px,卡片/面板 10px,胶囊(分段控件、小标签)999px
- 阴影:只有一档 `0 1px 3px rgba(0,0,0,.06)`,仅浮层和选中胶囊使用;卡片不用阴影,用 1px 描边

## 5. 布局

### 侧边栏(主界面)

```
┌──────────────────────────────┐
│ [icon] 视频标题(单行截断)     │ ← 头部:图标与标题同行,meta 一行小字
│ youtube · 312 句字幕          │   状态条不占独立行,内联在 meta 后
│ ┌──────────────────────────┐ │
│ │ 字幕 概览 笔记 助教 导出  │ │ ← 分段胶囊页签(吸顶)
│ └──────────────────────────┘ │
│           内容区             │
└──────────────────────────────┘
```

### 设置页

左栏(200px,白底):品牌 + 三个菜单项(选中态 = 左侧 3px 珊瑚条 + 浅底)。
右侧内容区(max-width 620px):字段以卡片(--surface + 1px 描边)为单位纵向排列,保存按钮吸底。

### 播放器内浮层

捕捉浮层与草稿提示条为白色面板(--surface 底 + 圆角 10px + 一档阴影),居中/顶部于播放器,强调色同为珊瑚红,与扩展页面完全一致。
截图编辑器例外:保持深色(图像标注工具惯例,深色突出画面内容)。

## 6. 组件规范

**按钮**(三档,不允许第四种):
- 主按钮:珊瑚红底白字,每个视图最多一个主按钮
- 次按钮:白底 1px 描边
- 危险/弱按钮:无边框灰字,hover 变红(删除 ×)或变主色
- 文案是动作本身:「保存」「导出到 Obsidian」,不用「确定/提交」

**页签**:分段胶囊(灰底容器 + 白色选中胶囊 + 一档阴影)。全产品只有这一种页签样式;垂直子标签(笔记区)用同款逻辑转 90°:左竖线选中态。

**时间码 chip**:等宽 11px、珊瑚字、--accent-soft 底、5px 圆角、可点击跳回视频。任何地方出现时间戳都用它,不允许裸文本时间戳。

**卡片**:白底 + 1px --line 描边 + 10px 圆角 + 12px 内边距。笔记、问答、模板行、设置字段都是它。

**输入框**:白底 + --line-strong 描边,聚焦时描边变珊瑚红。placeholder 只写格式示例(如「sk-...」),说明文字放下方 hint(12px, --dim)。

**空状态**:一句话 = 现状 + 动作邀请。「暂无笔记——观看中按 Ctrl+Shift+S 记录想法」。不放图标,不放情绪词。

**状态条**:内联小字(12px),成功 --ok、错误 --err、进行 --warn;4 秒后自动消失的成功提示不挡内容。

**Markdown 渲染内容**(自动笔记/助教/预览):标题 14/13px 两档;表格 12px 细线;代码用等宽字体浅底;公式用 KaTeX 默认样式,不再自定义。

## 7. 文案规范

- 用用户的词,不用系统的词:说「字幕」,不说「subs 缓存」;说「视频」,不说「videoKey」
- 主动语态,按钮即动作:「生成笔记」生成笔记
- 错误 = 发生了什么 + 怎么办:「API Key 未配置,请在设置页填写」;不道歉、不含糊
- 加载中说进度:「语音加载中… 首批 2/3」
- 同一动作全产品同名:生成草稿的按钮在哪都叫「生成 / 更新草稿」

## 8. 动效

- 只保留功能型动效:页签切换无动画;hover 变色 150ms;加载转圈
- 唯一允许的"性格"动效:品牌区的声波条纹(5 根竖条 1.6s 呼吸),`prefers-reduced-motion` 时静止
- 不做:入场动画、滚动触发、视差

## 9. 可访问性底线

- 键盘焦点可见:2px 珊瑚红 outline
- 文字对比度:正文 ≥ 4.5:1,辅助文字 ≥ 3:1(令牌已满足,改动后需复查)
- 所有可点元素 ≥ 24×24px 触达区
- `prefers-reduced-motion: reduce` 时所有动画停止

## 10. 验收清单(每次 UI 改动后过一遍)

- [ ] 颜色只用了令牌表里的值
- [ ] 时间戳是时间码 chip
- [ ] 每个视图最多一个主按钮
- [ ] 间距都是 4 的倍数,圆角只用了 6/10/999
- [ ] 新界面截图与侧边栏/设置页并排看,像同一个产品
- [ ] 空状态和报错按第 7 节口径写
